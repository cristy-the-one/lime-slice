# Modeler

* [Sketching and features](sketching.md) - Sketches, constraints, and history ops live in the app and in the Open CASCADE bridge, which the shell loads only when it is built.
* [Parameters](parameters.md) - A project can store named parameters. Expressions on steps and sketch sizes evaluate before the engine sees numbers.
* [Split to print](split-to-print.md) - A partition cuts one solid into pieces that fit a printer volume, with optional connectors, and can target the Form 4 for export.
* [Assemblies](assemblies.md) - An assembly is a tree of plate objects posed relative to each other. There is no mate solver.
