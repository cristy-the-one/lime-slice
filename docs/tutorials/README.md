# Modeler tutorials

Worked examples for Revolve, Loft, and Sweep in the desktop Model window. Each one is built in the real UI: the profile, the path or axis, the values, and the solid.

The tools are buttons on the sketch card in the left dock, and keys while a sketch is open. There is no rail button for them.

| | Example | What it shows |
| --- | --- | --- |
| [Revolve](revolve.md) | Cup | A closed wall on the XZ plane, spun 360° about V |
| | Grooved pulley | A bored profile, the angle dragged with Ctrl, then typed back to 360° |
| | Half bowl | A construction line as an offset axis, and a 180° turn |
| [Loft](loft.md) | Square-to-round duct | A 40 mm square on the bed and a circle 50 mm up, ruled |
| | Bottle | Three circles, smooth, from the body up through the neck |
| | Offset funnel | A small circle shifted sideways on a raised plane |
| [Sweep](sweep.md) | Bent pipe | A circle on YZ carried along a line and a tangent arc |
| | Tapered handle | A slot profile, and an end scale dragged then typed |
| | Cable guide | Two lines, a fillet so the corner can be swept, a rectangular profile |

Screenshots are 1440×900, dark theme. Sizes on the solid are the measure callouts.
